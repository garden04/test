## Git 용어 정리

### branch (브랜치)
- 독립적인 작업 공간입니다. 새로운 기능을 개발할 때 원본 코드를 건드리지 않고 별도로 작업할 수 있습니다.

### merge (병합)
- 여러 브랜치의 변경사항을 하나로 합치는 것입니다.

### push (푸시)
- 로컬 저장소의 커밋을 원격 저장소(GitHub)로 업로드하는 것입니다.

### pull (풀)
- 원격 저장소의 최신 변경사항을 로컬로 다운로드하는 것입니다.

### clone (클론)
- 원격 저장소를 내 컴퓨터로 복사하는 것입니다.

### remote (원격)
- 원격 저장소의 주소입니다. 보통 `origin`이라는 이름으로 GitHub 주소를 가리킵니다.

### working directory (작업 디렉토리)
- 현재 작업 중인 프로젝트 폴더입니다. 파일을 수정하고 편집하는 실제 작업 공간입니다.

### staging area (스테이징 영역)
- 커밋할 파일을 임시로 모아두는 대기 공간입니다. `git add` 명령어로 파일을 여기에 추가합니다.

### repository (저장소)
- Git이 프로젝트의 모든 변경 이력을 저장하는 곳입니다. `.git` 폴더가 로컬 저장소이고, GitHub는 원격 저장소입니다.

### commit (커밋)
- 변경 사항의 스냅샷을 저장하는 것입니다. "저장 시점"을 만들어 나중에 되돌릴 수 있습니다.

### clone (클론)
- 원격 저장소를 내 컴퓨터로 복사하는 것입니다.

### remote (원격)
- 원격 저장소의 주소입니다. 보통 `origin`이라는 이름으로 GitHub 주소를 가리킵니다.
